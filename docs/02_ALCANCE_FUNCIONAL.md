# Alcance funcional

| Módulo aprobado | Objetivo futuro                                                                          | Etapa 01                                     |
| --------------- | ---------------------------------------------------------------------------------------- | -------------------------------------------- |
| Tienda          | Inicio, categorías, búsqueda, filtros, ficha, carrito, checkout, destacados y responsive | Inicio, catálogo y ficha con datos estáticos |
| Productos       | CRUD, categorías, fotos, descripciones, SKU, códigos de barras, presentaciones y volumen | Catálogo ilustrativo                         |
| Inventario      | Stock, ingresos, entradas/salidas, ajustes y trazabilidad                                | Tabla visual sin modificaciones              |
| Multicanal      | Ventas propias y registro manual de Mercado Libre sobre inventario único                 | Indicadores ficticios                        |
| Comercial       | Pedidos, pagos Webpay o Mercado Pago, dashboard, ventas y control de acceso              | Dashboard público demostrativo               |

Excluidos: API/sincronización automática de Mercado Libre, facturación electrónica, contabilidad, POS avanzado, aplicaciones nativas, IA y automatizaciones complejas.

Restricciones actuales: ninguna tabla productiva, migración definitiva, autenticación, pago, inventario real, pedido persistente, integración externa ni despliegue. Las rutas de módulos futuros explican su estado; no representan funcionalidades terminadas. Cualquier ampliación requiere autorización.
